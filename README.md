# E-File Management System

Frontend electronic file/document management application built with HTML, CSS and JavaScript.

## Features
- Registration and login
- LocalStorage authentication/session
- Responsive dashboard
- File metadata upload workflow
- Search and category filtering
- Folders
- Trash / restore / permanent delete
- Shared-with-me demo data structure
- Profile editing
- Download demo action

## Run
Open `index.html` in a browser. No server or build process is required.

## Important
This is a frontend/localStorage project. Browser LocalStorage stores file metadata, not the actual uploaded binary files. A production version would use a backend and real file storage.
